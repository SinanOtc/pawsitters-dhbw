# Pawsitters - Pet Holiday Platform

Eine Plattform zur Vermittlung von Tierbetreuungsangeboten

## Team

- Kevin Christian Albrandt
- Sinan Oturucu
- Vincent Roland Scheibe

## Tech-Stack

Java 21 · Spring Boot · Maven · Thymeleaf · JUnit · H2

## Setup

```bash
./mvnw spring-boot:run     # App starten
./mvnw test                # Tests laufen lassen
./mvnw verify              # Build inkl. Tests
```
